Optimizer Settings

Exposure is the percentage of generated lineups containing a player: 50% means at most 5 of 10. Blank player caps use the default. Locks override the default cap; an explicit player cap below 100% conflicts with a lock. Minimums round up and maximums round down to whole lineups.

Each pair of lineups must differ by at least the selected number of players, regardless of roster slot. Start with 3 for more variety. More variety can reduce projected points or the number of lineups found. Locked players stay in every lineup. Lock or exclude players before generating. Demo results are for testing only and cannot be exported. Imported salaries define the active slate; use the matching contest file. Reimport if DraftKings changes eligibility.
